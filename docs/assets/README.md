- erd.png
- workflow.png

- ui-flow.png

## Source

Setiap diagram memiliki file Mermaid (.mmd) agar dapat diubah kembali.

Contoh:

erd.mmd → erd.png

workflow.mmd → workflow.png

Diagram dapat dirender menggunakan:

- Mermaid Live Editor
- VSCode Mermaid Preview
- GitHub Mermaid
- Mermaid CLI

Diagram PNG tidak boleh diedit secara langsung.

Perubahan dilakukan pada file .mmd kemudian dirender ulang.
